Frequently asked questions

The questions people ask most, answered plainly, including the parts that are awkward.

Does Circle upload my messages?

No. Circle has no account, no server and no analytics. Your archive is a database file on your own disk, and the model that answers questions runs on your own computer. The privacy notice lists exactly what is downloaded and what is not.

Does it work without the internet?

Yes, once set up. The only things Circle fetches from the internet are the Ollama installer and the model weights, and only after you click to allow it. After that, importing, searching and asking all work offline.

What does it cost?

Nothing. There is no subscription, no API key and no usage billing, because there is no hosted service being used.

Does it need an account or password?

No. There is no sign-in, because there is no service to sign in to.

What does it need from my computer?

A 64-bit Windows machine, about 1 GB of free disk space for the application, and several gigabytes more if Circle downloads the models for you. A machine with 16 GB of RAM runs it comfortably; a 4B model needs roughly 4 GB of that while answering.

Will it modify or delete my export files?

No. Circle reads the folder you point it at in place. It only ever moves a file if that file was already inside Circle's own working directory, which a folder you chose will not be.

Can I point it at Google Drive or OneDrive?

Yes, and many people do. Circle reads the folder where the drive client has already synced it. If a file has not been downloaded yet, Circle may take a moment longer on that file the first time it reads it.

How accurate is it?

Counting questions are exact, because they are counted in the database. Everything else is answered by a small language model running on your own hardware, and it can be wrong. It also sometimes answers correctly for the wrong reason. Treat answers as a starting point, and follow the citations it gives to check what it actually read.

Will it merge two different people into one?

Not on its own. When Circle is unsure whether two records are the same person it raises a suggestion and waits. Nothing is merged until you confirm it, and you can undo a merge.

Can other people see my archive?

Only anyone with access to your Windows account and your disk. Circle serves its own interface on a loopback address that only this machine can reach. It does not open a port on your network and it does not share anything.

How do I delete everything?

Uninstall Circle, then delete the Documents/Circle folder. Since nothing was ever copied anywhere else, that is the whole deletion. Your original exports are untouched.

Does it work on Mac or Linux?

Not yet. The published installer is Windows only. The source is open, and the parts that are platform-specific are small.

Can I use a different model?

Yes. Circle uses whatever Ollama reports as installed; you can choose another in Settings and it takes effect immediately. Counting questions will not change quality — they are not answered by the model at all.

Is the code available?

Yes. The project is open source and the repository link is in the footer of every page.

Still unanswered?

Raise an issue on the project's repository. If the answer turns out to be generally useful, it belongs in this page.
