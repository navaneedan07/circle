How Circle works

A plain account of what the application does to your files, in what order, and what it deliberately refuses to do.

1. You choose one folder

Circle watches exactly one folder, the one you pick. It is created by you, filled by you, and Circle creates nothing inside it. If the folder is a cloud drive, that is fine — it reads in place and leaves your files where they are.

2. It looks at each file once

For every file that appears, Circle works out what it is, checks it is a type it understands and not larger than a sensible limit, and fingerprints it with a checksum. If it has seen that exact file before, it skips it. That is why re-exporting your chats does not duplicate anything.

3. It parses what it recognises

File What Circle takes from it
WhatsApp export Conversations, messages, senders, timestamps, attachments
Telegram export Chats, messages, participants
Instagram / Meta export Each message thread separately, keyed by the thread folder, so two conversations never collapse into one
Email (.mbox, .eml) Sender, recipients, subject, date, body
Calendar (.ics) Events, times, attendees
Contacts (.vcf, CSV) Names, numbers, email addresses
Documents and notes Text, split into retrievable passages
Attachments Voice notes and images are copied into Circle's own media folder and stored once, by content hash

Most of a social data export is not conversations — it is ad interests, account settings and thousands of photographs. Circle skips that noise on purpose rather than filling your database with it.

4. It works out who is who

The same person appears under a phone number in one export, a handle in another and a display name in a third. Circle matches those into a single person using contacts you have imported and the shared identity of each thread.

When the evidence is genuinely ambiguous it does not guess. It files the case as a suggestion and asks you, and it will not merge two people on its own. You are always the one who decides who counts as one person.

5. It builds a local index

Messages, contacts and events go into one SQLite database. Each message and passage is also turned into a vector by a local embedding model, so that a question can find things by meaning rather than only by exact word.

This runs on your machine and is the slow part of a first import. You can keep using Circle while it happens; a question asked mid-import waits for the current batch rather than the whole run.

6. It answers a question

There are two kinds of question, and they are answered differently on purpose.

  • Counting questions — “who do I talk to most”, “how many messages last week” — are answered by counting your actual records in the database.
  • Everything else is answered by finding the most relevant passages (by meaning and by keyword), then asking the local model to answer using only those passages, citing each one.

That split exists because asking a small model to count through 100,000 messages produces a confident, invented number. Counting is something a database is simply better at.

The model is told to stay inside the evidence

The answer prompt contains only the passages Circle retrieved, and requires citations. If the model produces no valid citation, the answer is marked as insufficient rather than presented as fact. If there is not enough to go on, Circle says so instead of guessing.

What it does not do

  • It does not send your messages, your questions, or anything derived from them to any server. There is no server to send them to.
  • It does not read the contents of files it does not recognise. It skips them.
  • It does not edit, move or delete anything in your folder. Files are only ever moved if they were already inside Circle's own working directory.
  • It does not merge two people without you saying so, and it does not make claims about anyone's emotional or mental state.

Where things are kept

What Where
Your archive and everything derived from it Documents/Circle/circle.db
Copied media such as voice notes Documents/Circle/media
Your settings, including the folder you chose Documents/Circle/settings.json
Your original exports Untouched, wherever you keep them

Removing Circle and deleting that folder removes everything it held. There is no copy anywhere else and nothing to wait out.
