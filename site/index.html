Your messages already know who matters. Circle helps you ask.

Circle is a small Windows application. It reads the message exports you already have on disk, works out which messages belong to which person, and then answers questions like “who do I talk to most” or “what did we promise about the project”. Nothing is uploaded, because there is nowhere for it to be uploaded to.

Download for Windows macOS — soon Linux — soon

One installer, one window. No account, no server, no browser needed.

What it actually does

Reads files you already have

WhatsApp, Telegram, Instagram, X, email, calendar files and documents. It reads them where they sit, and never modifies, moves or deletes them.

Works out who is who

Numbers, handles and display names are matched across sources into one person each. When it is unsure it asks, and it never merges two people without you saying so.

Answers from your own machine

A local language model through Ollama reads your archive. No API key, no account, no per-question fee, no internet needed once it is set up.

Keeps one file

Everything it learns is a single SQLite database in your Documents folder. Delete that folder and the archive is gone.

Questions it can answer

  • Who do I talk to most, and who have I stopped talking to?
  • What did we last discuss with this person?
  • What should I remember before meeting them?
  • What are my recurring topics this year?
  • How many messages did I send last week?

Setting it up

  1. Run the installer, then open Circle from the Start menu.
  2. Circle checks for a local model first. If one is missing, one click installs Ollama and downloads gemma3:4b and nomic-embed-text for you. You are asked before anything is downloaded, and it all runs on your own hardware.
  3. Choose the one folder that holds your exports. Circle creates nothing inside it.

First run indexes everything, which takes a few minutes on a large archive. The model download is several gigabytes and happens once. You can keep asking questions while it imports.

What Circle does not do

  • It does not connect to any social account. It reads files.
  • It never merges two people without asking you first.
  • It does not send anything anywhere, because there is nowhere for it to send it.
  • It has no analytics, no telemetry and no crash reporting.

Where your data lives

In one SQLite file inside Documents/Circle/circle.db, on this machine. Your exports stay exactly where they are. Nothing is uploaded, synced or backed up anywhere you did not ask for. The full detail is in the privacy notice.

Honest limitations

  • Answers come from a small model running on your own computer. It can be wrong, and it can be confidently wrong. Treat an answer as a starting point for your own judgement, not a verified account of what someone said.
  • Counting questions are answered by counting your records rather than by the model, precisely because a small model asked to count 100,000 messages invents a confident number.
  • Windows only, for now.
