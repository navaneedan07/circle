A private memory layer for your relationships

Bring your own memories

Import the exports and files you already have from WhatsApp, Telegram, Instagram, X, email, calendars, contacts, documents, notes and voice recordings.

One person, one context

Circle connects names, handles, phone numbers and email addresses across sources. Uncertain matches become suggestions instead of silent merges.

Ask in plain language

Ask about recent conversations, promises, recurring topics, activity, meeting preparation and the things you want to remember.

Local by design

Your archive stays in a local SQLite database. Ollama runs Gemma and nomic-embed-text on your machine, so your memories do not need to leave it.

What you can ask

  • Who do I talk to most, and who have I stopped talking to?
  • What have we been talking about recently?
  • What did I promise them?
  • What should I remember before meeting them?
  • What topics keep coming up between us?
  • How many messages did I send last week?

Answers you can check

Circle combines SQLite full-text search with semantic vector retrieval, then gives the local model only the most relevant evidence. Answers include source snippets and citations so you can inspect the original context instead of treating the model as an authority.

Built with open, local AI

Circle uses Gemma 3:4B through Ollama for private reasoning and nomic-embed-text for local semantic search. After the one-time model setup, Circle can answer questions without an internet connection or a per-question API bill.

Exact questions such as counts and recent activity are answered directly from SQLite. Open-ended questions use hybrid retrieval and evidence-grounded generation. The result is a practical assistant that is useful without handing your personal archive to a cloud AI provider.

Setting it up

  1. Run the installer, then open Circle from the Start menu.
  2. Circle checks for a local model first. If one is missing, the setup flow installs Ollama and downloads gemma3:4b and nomic-embed-text for you. You are asked before anything is downloaded, and it all runs on your own hardware.
  3. Choose the one folder that holds your exports. Circle creates nothing inside it.

First run indexes everything, which takes a few minutes on a large archive. The model download is several gigabytes and happens once. You can keep asking questions while it imports.

What Circle does not do

  • It does not connect to any social account. It reads files.
  • It never merges two people without asking you first.
  • It does not send anything anywhere, because there is nowhere for it to send it.
  • It has no required cloud account, hosted archive or cloud LLM.

Where your data lives

In one SQLite file inside Documents/Circle/circle.db, on this machine. Your exports stay exactly where they are. Nothing is uploaded, synced or backed up anywhere you did not ask for. The full detail is in the privacy notice.

Honest limitations

  • Answers come from a small model running on your own computer. It can be wrong, and it can be confidently wrong. Treat an answer as a starting point for your own judgement, not a verified account of what someone said.
  • Counting questions are answered by counting your records rather than by the model, precisely because a small model asked to count 100,000 messages invents a confident number.
  • Windows only, for now.
